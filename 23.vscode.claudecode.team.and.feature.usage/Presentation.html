Team & Feature Usage Tracking

Tag every Claude Code span with the feature being built — then see exactly how much each developer spent on each feature, by team, in Application Insights.

OTEL_RESOURCE_ATTRIBUTES feature=cool-feature department=dev App Insights · KQL Cost per feature
Context

The problem: who spent what on which feature?

Sample 22 gives you raw Claude Code telemetry — token counts, cost, and prompts per developer. But at team scale you need to answer:

QuestionWithout feature taggingWith feature tagging
Feature cost breakdownAll AI spend is mixed togetherSum cost_usd grouped by feature
Developer effort per featureOnly global totals visibleKQL join on user.email + feature
Department chargebackCannot split by teamGroup by department attribute
Sprint cost estimationNo story-level dataFilter by feature for the sprint
Solution

OTEL_RESOURCE_ATTRIBUTES in .claude/settings.json

Add OTEL_RESOURCE_ATTRIBUTES to the .claude/settings.json env block. Every span emitted while working in that workspace inherits these attributes automatically.

{
  "env": {
    "CLAUDE_CODE_ENABLE_TELEMETRY": "1",
    "OTEL_METRICS_EXPORTER":        "otlp",
    "OTEL_LOGS_EXPORTER":           "otlp",
    "OTEL_EXPORTER_OTLP_PROTOCOL":  "http/protobuf",
    "OTEL_EXPORTER_OTLP_ENDPOINT":  "http://localhost:4318",
    "OTEL_LOG_USER_PROMPTS":        "1",
    "OTEL_LOG_TOOL_DETAILS":        "1",
    "OTEL_METRICS_INCLUDE_VERSION":  "true",

    "OTEL_RESOURCE_ATTRIBUTES":     "department=dev,feature=cool-feature2"
  }
}
Workflow

Developer workflow — one setting change per feature

Each time a developer starts working on a new feature they update the feature value in OTEL_RESOURCE_ATTRIBUTES. All subsequent Claude Code activity is automatically tagged to that feature.

1
Pick up a new feature / story
Update feature=my-new-feature in .claude/settings.json
2
Use Claude Code normally
Ask questions, run commands, edit files — telemetry flows automatically
3
Query App Insights
See tokens, cost, and requests grouped by feature and developer
Resource Attributes

Useful attributes to include

AttributeExample valuePurpose in App Insights
featurecool-feature2Group all AI spend for a specific feature or story
departmentdevEnable department-level chargeback reporting
service.namemy-serviceAppears as cloud_RoleName — groups spans in the App Map
team.idplatformFilter usage by team in multi-team organisations
deployment.environmentdev / stagingSeparate dev-time AI usage from production workloads

Note: These attributes are merged into every span and log record at the OTel SDK level — you do not need to change any code. Just update the settings file.

Log Analytics / KQL

Tokens and cost per developer per feature

traces
| where message == "claude_code.api_request"
| extend feature_               = tostring(customDimensions.feature)
| extend cost_usd_              = todecimal(customDimensions.cost_usd)
| extend input_tokens_          = tolong(customDimensions.input_tokens)
| extend output_tokens_         = tolong(customDimensions.output_tokens)
| extend user_email_            = tostring(customDimensions["user.email"])
| extend cache_creation_tokens_ = tolong(customDimensions.cache_creation_tokens)
| extend cache_read_tokens_     = tolong(customDimensions.cache_read_tokens)
| summarize
    CostUSD             = sum(cost_usd_),
    Requests            = count(),
    InputTokens         = sum(input_tokens_),
    OutputTokens        = sum(output_tokens_),
    CacheCreationTokens = sum(cache_creation_tokens_),
    CacheReadTokens     = sum(cache_read_tokens_)
    by
    Feature = feature_,
    Email   = user_email_

This is the core query — it shows you exactly how much each developer has spent on each feature in one table. Sort by CostUSD desc to find the most expensive features.

Log Analytics / KQL

Additional queries

Cost per feature · all developers
traces
| where message == "claude_code.api_request"
| extend feature_ = tostring(
    customDimensions.feature)
| extend cost_    = todecimal(
    customDimensions.cost_usd)
| summarize
    TotalCostUSD = sum(cost_),
    Requests     = count()
    by Feature = feature_
| order by TotalCostUSD desc
Daily spend by department
traces
| where message == "claude_code.api_request"
| extend dept_ = tostring(
    customDimensions.department)
| extend cost_ = todecimal(
    customDimensions.cost_usd)
| summarize
    DailyCostUSD = sum(cost_)
    by dept_,
       bin(timestamp, 1d)
| order by timestamp desc
