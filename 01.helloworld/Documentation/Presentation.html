Overview

What this sample does

Sends a single chat message to Azure OpenAI, prints the response text and token usage to the terminal. It is the baseline — the smallest working example before adding observability, agents or gateways.

ComponentRole
AzureOpenAIClientConnects to Azure OpenAI with an endpoint URL + API key
IChatClientProvider-neutral abstraction from Microsoft.Extensions.AI
GetResponseAsync()Sends the prompt and awaits the model's reply
response.UsageExposes InputTokenCount and OutputTokenCount
Key Code

Building and calling the client

IChatClient chatClient = new AzureOpenAIClient(
    new Uri(endpoint),
    new AzureKeyCredential(apiKey))
    .GetChatClient(deploymentName)
    .AsIChatClient()    // wrap in the ME.AI abstraction
    .AsBuilder()
    .Build();

var response = await chatClient.GetResponseAsync(
    "Hello! Can you tell me one interesting fact about AI?");

Console.WriteLine(response.Text);
Console.WriteLine($"Tokens — Input: {response.Usage?.InputTokenCount}, Output: {response.Usage?.OutputTokenCount}");

The builder chain wraps the raw Azure SDK client in the IChatClient abstraction. This means you can swap the underlying provider (e.g. Ollama, OpenAI) later without changing the calling code.

Note: There is no OpenTelemetry setup here — no spans, no metrics, no App Insights export. That is intentionally added in the next sample (02 · helloworld.logging).
