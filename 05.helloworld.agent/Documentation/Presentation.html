Agent Tools

Three tools wired to the model

GetCurrentDateTime
Returns the current UTC date and time as a formatted string
GetWeather(city)
Returns hard-coded weather conditions for London, Tokyo, New York, Sydney, Paris
Calculate(a, op, b)
Performs + − × ÷ on two numbers and returns the result
AIFunction getDateTimeTool = AIFunctionFactory.Create(
    () => DateTime.UtcNow.ToString("R"),
    "GetCurrentDateTime",
    "Returns the current UTC date and time.");

var options = new ChatOptions
{
    Tools = new List<AITool> { getDateTimeTool, getWeatherTool, calculateTool },
    ToolMode = ChatToolMode.Auto,
};
Agentic Loop

How UseFunctionInvocation() works

1
App sends user message + tool definitions to the model
2
Model responds with a tool_call (e.g. GetCurrentDateTime)
3
UseFunctionInvocation middleware executes the tool locally
4
Tool result is appended to message history and sent back to the model
5
Steps 2–4 repeat until the model returns a plain text answer

There is no manual loop code in Program.cs. UseFunctionInvocation() handles all of steps 2–4. UseOpenTelemetry() is registered outside it, so it records each individual model call as a separate child span.

App Insights Agent Preview

Custom dependency span — simulating Foundry agent tags

App Insights Agent Preview looks for gen_ai.agent.name and gen_ai.operation.name on a Client-kind dependency span. The Microsoft.Extensions.AI SDK does not set these automatically — so we create a custom wrapper span around the entire GetResponseAsync call.

// Custom Client span wrapping the full agent invocation (including tool-call loop).
// Setting gen_ai tags here makes it appear in App Insights Agent Preview
// without needing to propagate tags to every child chat span.
ChatResponse response;
using (var agentSpan = appSource.StartActivity("invoke helloworld-agent", ActivityKind.Client))
{
    agentSpan?.SetTag("gen_ai.operation.name", "invoke_agent");  // required for Agent Preview
    agentSpan?.SetTag("gen_ai.agent.name",     "helloworld-agent"); // agent identity in the dashboard
    agentSpan?.SetTag("gen_ai.system",         "openai");
    agentSpan?.SetTag("gen_ai.request.model",  deploymentName);

    response = await chatClient.GetResponseAsync(messages, options);
    agentSpan?.SetStatus(ActivityStatusCode.Ok);
}
Resulting trace tree

  └── invoke helloworld-agent  (Client) ← gen_ai.agent.name here
        ├── chat gpt-4o  [1]
        ├── chat gpt-4o  [2]
        └── chat gpt-4o  [n]
Without this pattern

The individual chat gpt-4o spans carry no agent identity. App Insights Agent Preview has nothing to group them under and the agent does not appear in the dashboard.
