Overview

What's new vs Hello World

Same single-prompt call — but now every AI request is automatically instrumented. The UseOpenTelemetry() middleware adds a child span for each model call. Prompt and response text are not captured.

ComponentRole
UseOpenTelemetry()Middleware — auto-creates a child span for every GetResponseAsync call
TracerProviderPipeline: Console exporter + Azure Monitor (App Insights) exporter
MeterProviderPipeline: token usage + operation duration metrics to App Insights
StartActivity("run-ai-prompt", Server)Root span — App Insights classifies Server-kind spans as Requests
ForceFlush()Ensures all buffered telemetry is exported before the process exits
Key Code

OpenTelemetry setup + middleware

// Traces pipeline
using var tracerProvider = Sdk.CreateTracerProviderBuilder()
    .AddSource("helloworld-logging")
    .AddSource("Microsoft.Extensions.AI")
    .AddConsoleExporter()
    .AddAzureMonitorTraceExporter(o => o.ConnectionString = appInsightsConnectionString)
    .Build();

// Metrics pipeline
using var meterProvider = Sdk.CreateMeterProviderBuilder()
    .AddMeter("Experimental.Microsoft.Extensions.AI")
    .AddAzureMonitorMetricExporter(o => o.ConnectionString = appInsightsConnectionString)
    .Build();

// Client with OTel middleware (no sensitive data)
IChatClient chatClient = new AzureOpenAIClient(...)
    .AsBuilder()
    .UseOpenTelemetry()   // ← EnableSensitiveData defaults to false
    .Build();

using (appSource.StartActivity("run-ai-prompt", ActivityKind.Server))
{
    var response = await chatClient.GetResponseAsync(prompt);
}

The root span run-ai-prompt uses ActivityKind.Server — App Insights classifies this as a Request. The child chat gpt-4o span becomes a Dependency nested beneath it.

Message Sequence

Step-by-step call sequence

sequenceDiagram participant App as Console App participant OTel as OpenTelemetry SDK participant AOAI as Azure OpenAI participant Console as Terminal participant AppIns as Application Insights App->>OTel: Build TracerProvider & MeterProvider App->>OTel: StartActivity("run-ai-prompt", Server) Note over App,OTel: Root span opens — kind=Server so App Insights classifies it as a Request App->>AOAI: IChatClient.GetResponseAsync(prompt) Note over App,AOAI: UseOpenTelemetry middleware creates child span "chat gpt-4o" AOAI-->>App: ChatResponse (text + usage) App->>OTel: SetTag(ai.input_tokens, ai.output_tokens) App->>OTel: SetStatus(Ok) + EndActivity Note over App,OTel: Root span closes and is handed to the exporter queue App->>OTel: ForceFlush (traces + metrics) OTel->>Console: Print spans and metrics to terminal OTel->>AppIns: Export via Azure Monitor exporter

Log Analytics / KQL

Useful queries for this sample

Dependencies — All AI calls with token counts
dependencies
| where type == "Other"
| extend gen_ai_provider_name_     = tostring(customDimensions["gen_ai.provider.name"])
| extend gen_ai_request_model_      = tostring(customDimensions["gen_ai.request.model"])
| extend gen_ai_usage_input_tokens_  = tostring(customDimensions["gen_ai.usage.input_tokens"])
| extend gen_ai_usage_output_tokens_ = tostring(customDimensions["gen_ai.usage.output_tokens"])
| project timestamp, operation_Id, name, gen_ai_provider_name_, gen_ai_request_model_,
          gen_ai_usage_input_tokens_, gen_ai_usage_output_tokens_
| order by timestamp desc
Token usage by type · per hour
customMetrics
| where name == "gen_ai.client.token.usage"
| extend tokenType = tostring(
    customDimensions["gen_ai.token.type"])
| summarize totalTokens = sum(value)
    by tokenType, bin(timestamp, 1h)
| order by timestamp desc
Token usage by app · per hour
customMetrics
| where name == "gen_ai.client.token.usage"
| summarize totalTokens = sum(value)
    by cloud_RoleName,
       bin(timestamp, 1h)
| order by timestamp desc
