Overview

Why capture Copilot telemetry?

GitHub Copilot Chat already emits OpenTelemetry spans internally. Enabling export lets you send those spans to your own collector — giving you visibility that is otherwise hidden inside the extension.

What you getWhy it matters
Token counts per interactionTrack consumption and forecast cost across your team
Latency per AI callSpot slow models or degraded endpoints
Prompt + response contentDebug agent outputs and review AI-generated content (opt-in)
Resource attributes per sessionTag spans with feature name, work item ID, team, cost centre
End-to-end trace contextCorrelate Copilot spans with your own app traces in App Insights
Architecture

How the telemetry flows

→
OTel Collectorlocalhost:4318 (HTTP) — sample 20
→

The Copilot extension is configured via settings.json or environment variables to export OTLP spans over HTTP to the collector. The collector (see sample 20) forwards them to Azure Monitor.

Pre-requisite: The OpenTelemetry Collector from sample 20 must be running and listening on http://localhost:4318 before you open VS Code.

Configuration — Settings

Configure via VS Code settings

Add to .vscode/settings.json for workspace scope, or to %APPDATA%\Code\User\settings.json for all workspaces.

{
  "github.copilot.chat.otel.enabled":        true,
  "github.copilot.chat.otel.exporterType":   "otlp-http",
  "github.copilot.chat.otel.otlpEndpoint":  "http://localhost:4318",
  "github.copilot.chat.otel.captureContent": true
}
Workspace scope

Settings in .vscode/settings.json only apply to that project. Commit to source control to share with the team.

User scope

User settings apply to every project on this machine. Open with Ctrl+Shift+P → Preferences: Open User Settings (JSON).

Settings Reference

What each setting does

SettingTypeDescription
otel.enabled boolean Turns OTel export on or off. Set false to disable without removing the other settings.
otel.exporterType string otlp-http sends spans over HTTP (port 4318). Use otlp-grpc for gRPC (port 4317). otlp-http is most compatible.
otel.otlpEndpoint string URL of your OTel Collector. http://localhost:4318 targets the Windows service from sample 20. Change host/port if your collector is elsewhere.
otel.captureContent boolean When true, the actual prompt and response text are included in spans as gen_ai.prompt and gen_ai.completion. Useful for debugging but means sensitive content reaches App Insights.

⚠ Content capture: Only enable captureContent when you understand that prompt and response text will be stored in Application Insights. Review your organisation's data handling policies before enabling.

What you see in Application Insights

Trace · Dependency
gen_ai / chat
One span per Copilot model call. Includes model name, token counts, latency.
Span attribute

The prompt text sent to the model. Only present when captureContent = true.
Span attribute

The model response text. Only present when captureContent = true.
Span attribute

The model that handled the request, e.g. gpt-4o or claude-3-7-sonnet.
Log Analytics / KQL

Useful queries

All Copilot AI calls — with token counts and prompts
dependencies
| extend model        = tostring(customDimensions["gen_ai.request.model"])
| extend inputTokens  = toint(customDimensions["gen_ai.usage.input_tokens"])
| extend outputTokens = toint(customDimensions["gen_ai.usage.output_tokens"])
| extend prompt       = tostring(customDimensions["gen_ai.prompt"])
| project timestamp, model, inputTokens, outputTokens, duration, prompt
| order by timestamp desc
Token usage by model · per hour
dependencies
| extend model        = tostring(
    customDimensions["gen_ai.request.model"])
| extend inputTokens  = toint(
    customDimensions["gen_ai.usage.input_tokens"])
| extend outputTokens = toint(
    customDimensions["gen_ai.usage.output_tokens"])
| summarize
    totalIn  = sum(inputTokens),
    totalOut = sum(outputTokens)
    by model, bin(timestamp, 1h)
| order by timestamp desc
Slowest AI calls · p95 latency
dependencies
| extend model = tostring(
    customDimensions["gen_ai.request.model"])
| summarize
    p95 = percentile(duration, 95),
    avg = avg(duration),
    calls = count()
    by model
| order by p95 desc
