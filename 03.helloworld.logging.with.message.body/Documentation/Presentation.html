Production Consideration

When to use — and when not to

✓ Use when…
  • Debugging prompt quality in development
  • Auditing model responses in a controlled staging env
  • Compliance requirements mandate full prompt logging
  • Data classification allows AI content in telemetry
✗ Avoid when…
  • Prompts contain PII or customer data
  • Your App Insights workspace has broad access
  • Responses may contain proprietary information
  • Running in production without a data retention policy

App Insights stores these as Custom Properties on the dependency span — visible to anyone with access to the workspace.

App Insights Tables

dependencies vs genAIContent

Aspect dependencies genAIContent
Table type Standard App Insights table — always present Dedicated AI telemetry table — emitted by the Semantic Kernel / OTEL AI exporter
Message content location customDimensions["gen_ai.input.messages"]
customDimensions["gen_ai.output.messages"]		 First-class columns: inputMessages & outputMessages
Model field customDimensions["gen_ai.request.model"] Top-level column: modelName
HTTP / call metadata duration, success, name (e.g. chat gpt-4o) — full HTTP span detail Not present — AI content only
KQL complexity to extract content High — nested parse_json(tostring(...)) on customDimensions Lower — parse directly from inputMessages / outputMessages
Best used for Call tracing, latency & error analysis Prompt/response auditing, content review, compliance

Both tables are populated on the same request — join on operation_Id to correlate HTTP timing from dependencies with message content from genAIContent.

Log Analytics / KQL

Querying prompt & response content

genAIContent — logged prompt & response text (last 1 h)
genAIContent
| where timestamp > ago(1h)
| extend input_content_  = tostring(parse_json(tostring(parse_json(inputMessages)[0].parts))[0].content)
| extend output_content_ = tostring(parse_json(tostring(parse_json(outputMessages)[0].parts))[0].content)
| extend gen_ai_usage_input_tokens_  = tostring(customDimensions.["gen_ai.usage.input_tokens"])
| extend gen_ai_usage_output_tokens_ = tostring(customDimensions.["gen_ai.usage.output_tokens"])
| extend gen_ai_response_model_      = tostring(customDimensions.["gen_ai.response.model"])
| project timestamp, operation_Id, modelName, gen_ai_usage_input_tokens_,
          gen_ai_usage_output_tokens_, gen_ai_response_model_, input_content_, output_content_
Dependencies — prompt & response from span attributes
dependencies
| where timestamp > ago(1h)
| extend input_content_  = tostring(parse_json(tostring(
    parse_json(tostring(customDimensions.["gen_ai.input.messages"]))[0].parts))[0].content)
| extend output_content_ = tostring(parse_json(tostring(
    parse_json(tostring(customDimensions.["gen_ai.output.messages"]))[0].parts))[0].content)
| extend gen_ai_request_model_ = tostring(customDimensions.["gen_ai.request.model"])
| project timestamp, operation_Id, name, gen_ai_request_model_,
          input_content_, output_content_, success, duration
